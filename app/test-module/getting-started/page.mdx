# Getting Started with Text Mode

### Launching Text Mode

Text Mode is available directly in the Reex API Builder web app:

1. Visit [https://reex-api-builder.toolshq.app/](https://reex-api-builder.toolshq.app/)
2. Click the **Test API** button in the bottom-right corner of the page.

### Switching from Other Modes

If you are currently in Standalone or Project Mode, click the floating **Test API** button in the bottom-right corner to switch to Text Mode.

> **Auto-save enabled:** All your work in Text Mode is automatically saved in real-time. You won't lose progress even if you close the browser.
