# Getting Started with Standalone Mode

Reex API Builder defaults to Standalone Mode when no project is connected. The app operates in one of three modes at any time: **Project Mode**, **Standalone Mode** or **Test Mode**.

### Launching Standalone Mode

Visit the web app directly to launch in Standalone Mode:

[https://reex-api-builder.toolshq.app/](https://reex-api-builder.toolshq.app/)

No setup is required — the app is ready for you to import and test collections immediately.

### Switching from Project Mode

If you are currently in Project Mode, click the **"Switch to Standalone Mode"** button in the bottom-right corner of the app.
